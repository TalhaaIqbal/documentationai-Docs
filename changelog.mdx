## Release History

<Update label="2024-10-15" description="v2.1.0" tags={["feature", "improvement"]}>

## New Features

- Added real-time collaborative editing with cursor tracking
- Implemented advanced search with fuzzy matching and filters
- Introduced document versioning with diff visualization
- Added support for custom metadata fields

## Improvements

- Enhanced performance for large document repositories
- Improved mobile responsiveness across all interfaces
- Updated API rate limits and added burst handling
- Better error messages and validation feedback

</Update>

<Update label="2024-09-20" description="v2.0.0" tags={["feature", "breaking"]}>

## New Features

- Complete API redesign with RESTful endpoints
- New folder-based organization system
- Integration support for GitHub, Slack, and Jira
- Advanced permission management

## Breaking Changes

- API endpoints now require authentication headers
- Folder structure changed from flat to hierarchical
- Removed legacy webhook format in favor of new event system

</Update>

<Update label="2024-08-10" description="v1.5.0" tags={["feature", "bugfix"]}>

## New Features

- Added document templates for common use cases
- Implemented bulk operations for document management
- New analytics dashboard for usage tracking
- Support for document comments and annotations

## Bug Fixes

- Fixed search indexing issues with special characters
- Resolved memory leaks in long-running processes
- Corrected timezone handling in date filters
- Fixed permission inheritance in nested folders

</Update>
